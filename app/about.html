BLE Mouse Controller

A CircuitPython project for continuous mouse movement and keyboard input, controllable wirelessly via Bluetooth from any browser with Web Bluetooth support.

Launch App GitHub ⬇ Device Files

Device Setup

  1. Download the device files using the ⬇ Device Files button above and extract the zip.
  2. Plug in the board while holding the button to enter bootloader mode — it appears as a MDBT50QRX USB drive. Flash CircuitPython by dragging device/firmware/adafruit-circuitpython-raytac_mdbt50q-rx-en_US-10.1.3.uf2 onto the drive. The board reboots as CIRCUITPY.
  3. Copy the following from the extracted zip onto the CIRCUITPY drive: 
    device/code.py   →  CIRCUITPY/code.py
device/lib/      →  CIRCUITPY/lib/
device/secret.txt →  CIRCUITPY/secret.txt  (edit password first)
  4. The code starts automatically on boot. The LED lights up when auto-movement is active.

Linux users: always run sync after copying files to prevent empty files caused by the OS flushing writes after the device reboots:

cp code.py /media/$USER/CIRCUITPY/ && sync

Hardware

Designed for the MDBT50Q-RX (nRF52840) running CircuitPython 10. The board acts as a USB HID device (mouse + keyboard) connected to a PC, phone, or tablet, while being controlled wirelessly from a second device over BLE UART.

Web App Features

  • Connect / disconnect to the board via BLE (requires Chrome or any Chromium-based browser)
  • Auto-movement: Start, Stop, Toggle — keeps the cursor active to prevent screensaver
  • Mouse controls: directional pad, custom X/Y move, left/middle/right click, scroll
  • Type Text — send text to be typed via USB HID on the connected PC
  • Cipher Text — AES-128-CTR encrypted text; the device decrypts and types it, protecting passwords over BLE
  • Speech to Keyboard (Voice tab) — dictate in Italian or English; the transcript is typed on the PC
  • Keyboard Layout (Settings) — US, Italian, UK, German, French or Spanish, to match the OS of the destination machine
  • Installable as a PWA on Android; updates itself in place (an Update available → Reload banner, never a reinstall)
  • Updates (Settings) — app and dongle firmware versions, and Update over USB from Chrome/Edge on the PC the dongle is plugged into

BLE Commands

CommandAction
STARTEnable auto-movement
STOPDisable auto-movement
TOGGLEToggle auto-movement on/off
MOVE x yMove mouse by x,y pixels
CLICK [LEFT|RIGHT|MIDDLE]Mouse click
SCROLL nScroll n steps (positive = up)
TYPE textType text via USB HID keyboard
KEY namePress one key (e.g. KEY ENTER)
LAYOUT codeSwitch keyboard layout: US/EN, IT, UK, DE, FR, ES
LAYOUTSList the layouts installed on the dongle
VERSIONReply with the firmware version
CIPHER <b64>Decrypt AES-128-CTR payload and type it

Keyboard Layout

The layout setting on the dongle must match the OS keyboard layout of the machine it is plugged into — not the machine running the browser. If they differ, special characters (like @) will produce the wrong output.


Each non-US layout needs its keyboard_layout_win_xx.mpy in the /lib folder on the CIRCUITPY drive. The release package includes IT, UK, DE, FR and ES (from the Neradoc keyboard layouts releases). Use Layout test in Settings to check that the setting matches the PC.

Speech to Keyboard

Open the Voice tab, pick the language you speak, then hold the mic button while you talk (or tap once to start and again to stop). The recording is transcribed by the DuDu worker, and the text appears in an editable box. Type it sends it to the PC. Turn on Type automatically to skip the check.


Setup: Settings → Speech to Keyboard → enter your worker API key → Save → Test connection. The speech language and the keyboard layout are separate settings: accented letters are typed only when the PC's layout has them. Don't dictate passwords; use Cipher.

Cipher — Secure Password Typing

The Cipher feature lets you type passwords over BLE without sending them in plaintext. The web app encrypts the text with AES-128-CTR using a pre-shared key, and the device decrypts and types it via USB HID.


The pre-shared password is stored in secret.txt on the device and in localStorage in the browser. Physical access to either defeats the protection.

Requirements

  • Chrome or any Chromium-based browser (Web Bluetooth required)
  • The app must be served over HTTPS — Web Bluetooth does not work over plain HTTP
  • A paired BLE device running the CircuitPython firmware
